# Terminate: A terminal library
## About
Terminate is a terminal library allowing advanced manipulatiom of the console \(e.g. changing text color and cursor position\) and aims to be a **modern and cross-platform terminal library**,
written in **C++**.

Terminate was started because we need a **modern alternative to** `ncurses` **in the world**, and because `ncurses` doesn't have progress bars.
